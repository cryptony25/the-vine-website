# Images

Photos for the site go in this folder.

## Gallery photos

The Gallery page expects these files:

- `gallery-1.jpg` — studio space
- `gallery-2.jpg` — one-on-one training session
- `gallery-3.jpg` — small group training
- `gallery-4.jpg` — equipment / weights area
- `gallery-5.jpg` — trainer coaching a client
- `gallery-6.jpg` — client celebrating progress

Until real photos are added, the Gallery page will show broken image icons
with the alt text visible. That is expected.

## Naming rules

- All lowercase
- Words separated by hyphens, never spaces
- Keep the `.jpg` extension consistent with what the HTML expects
