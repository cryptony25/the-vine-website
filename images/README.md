## Licensing

All stock photos here are from Unsplash under the Unsplash License, which
allows free commercial use with no attribution required. Unsplash+ premium
photos were deliberately avoided because they are not free.

**Do not** add photos found through a search engine. Most are copyrighted, and
small businesses do get invoiced for using them.

## Replacing a photo

Save the new photo over the existing filename and the site picks it up with no
code changes. Before saving, resize to roughly 1200px wide and save as JPEG at
around 70% quality to keep the file small.

## Naming rules

- All lowercase
- Words separated by hyphens, never spaces
- Keep the `.jpg` extension consistent with what the HTML expects
